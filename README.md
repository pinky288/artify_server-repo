Artify Server

This is the backend server for Artify, an online platform for artists and artworks.



 Features
- REST API endpoints for artists and artworks
- Add or remove artworks from favorites
- Like/unlike functionality for artworks
- Fetch single artwork details
- MongoDB integration for storing artists and favorites

Tech Stack
- Node.js
- Express.js
- MongoDB
- Cors middleware
